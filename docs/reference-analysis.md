# 参考视频分析与复刻方案

## 视频规格与复刻范围

- 片段 ID：`bfa66bb1-df13-4166-88a0-54a8b7fd531f`。
- 参考画面为 1920 × 1080、30 fps；容器时长约 30.059 秒。复刻采用 900 帧，即 30 秒。
- 主题是一只砖红色方块角色“小克”在手绘剪辑软件内快速完成素材导入、剪切、特效、字幕、调色、卡点与导出。
- 分析依据为本地下载参考片段及逐秒关键帧。公开工程不包含原参考视频、参考抽帧、原音轨、签名下载地址或绑定凭证。
- 动画主体使用 React/Remotion 与 SVG 重新绘制；素材缩略图、手机内容、角色、界面和装饰均为矢量绘制。音效由本工程 Python 脚本自行合成，不采样参考音轨。字体使用随工程提供的 LXGW WenKai Regular（霞鹜文楷），授权为 SIL Open Font License 1.1，详见 `public/fonts/OFL.txt`。

## 构图与视觉语言

软件窗口几乎铺满 16:9 画布，奶油色纸面和深褐色轮廓形成统一底色。窗口上方是文件名、时间码和青绿色“导出”按钮；左边为素材/转场/文字侧栏，中间为竖屏手机预览，右边为四条调整滑杆。下部是占画面约三分之一的多轨时间线，含黄色文字轨、缩略图视频轨及浅紫色波形轨。界面标签与时间线本身也是叙事的一部分。

外壳、面板与卡片使用圆角矩形、约 3–5 px 的深色描边、轻微偏移和柔和阴影，模拟手绘墨线。手机黑色圆角外框比面板描边明显更厚，有顶部听筒/开孔、细侧键和底部投影。纸面留白较多，操作动作通常通过角色的长胳膊、红色播放头、黄色高亮和大号手写口号引导注意。

小克是低矮的砖红色方块：短腿、小手、圆眼或弯眼、浅色高光以及轻微红晕。它在时间线上移动，胳膊可夸张伸长到侧栏或调整面板。对错误、撤销与完成的反应由眉毛、眼形、旋转与弹跳表达。结尾小克戴墨镜，手机放大为主体，软件背景整体变淡。

## 字体与文字层次

参考的主要中文为带手写笔触的圆润楷书/手写体观感，英文文件名和数字也带轻微不规则感。复刻使用 LXGW WenKai Regular 近似这一视觉风格，并非对原片字体身份的认定。界面正文大多为深褐色；次要状态使用低对比灰。标题与口号使用更粗的中文字形，黄色填充配深色描边和偏移阴影；“饱和度拉满”等状态字可使用粉色或青绿色强调。底部时间尺数字与时间码应保持易读。

可见文本包括窗口文件名“小克剪辑_最终版_打死不改(3).mp4”、素材/转场/文字、调整、闪光、饱和度、缩放冲击、速度、Ctrl+Z、卡点、导出，以及结尾“30 秒剪完”“Opus 5.5”“拿捏了！”等。这些内容属于参考画面数据，不代表本工程调用了相应模型或产品。

下表时间为对逐秒关键帧的近似分段。复刻以帧驱动动作，快速的小动作和镜头强调可在相邻分段间重叠。

| --- | --- | --- |
| 0–1 s | 奶油背景中央的小代码窗口逐字出现 | 小尺寸窗口、打字光标；为后续剪辑工作台建立开场 |
| 1–2 s | 铅笔勾出完整软件界面，手机和各面板出现 | 线条绘制/渐显，镜头迅速落到完整工作区 |

| 6–8 s | 识别并剪去灰色/不需要的素材段，出现剪刀与垃圾桶 | 拉面预览短暂失色，切片分开后落入垃圾桶，保留片段回弹补位 |
| 8–9 s | 小克整理剩余素材，界面准备切换工具 | 手臂收回、时间线轻推移，用动作衔接下一操作 |

## 动画实现原则

所有动画应由 `useCurrentFrame()`、插值和弹簧函数决定，避免运行时随机数或真实时间导致渲染不一致。位移与旋转有小幅过冲；手臂拖拽采用清晰的弧线，接触目标时安排短暂停顿。软件外壳整体保持稳定，镜头在剪切、字幕和滑杆操作时适度平移/放大，结尾再切换为手机与便签主导的构图。

四种素材预览各自保持独立配色与图案，时间线缩略图应复用对应 SVG 场景。手机预览依照剪辑内容切换，不直接嵌入参考视频。较暗的调色过程、饱和度夸张与手绘口号是剧情动作，应保持短促，避免长时间遮住操作过程。

## 原创合成音效

`scripts/generate-audio.py` 仅使用 Python 标准库生成 30 秒、48 kHz、双声道 PCM WAV，再通过 FFmpeg 转为公开工程使用的 AAC/M4A。固定随机种子保证结果可重复；无旁白、无外部采样、无参考音轨混入。音轨以短促鼠标点击、纸擦、剪切、轻音阶、极轻的节拍与导出完成铃声对应动作。

| 时间 | 合成声音 |
| --- | --- |
| 0–2 s | 轻键盘声、界面出现的柔和上行音 |
| 2 s | 开工的两颗木质拨音 |
| 3–5 s | 拖素材的纸擦/滑动声与吸附点击 |
| 6–9 s | 成对剪切声、删除落下声、补位点击 |
| 10–12 s | 转场操作点击与短促亮铃 |
| 13–16 s | 输入键声、撤销的下行拨音、恢复提示 |
| 17–20 s | 拖滑杆的柔滑擦声、夸张音高上行与回落 |
| 22–24 s | 卡点按钮、轻拍节奏与标记吸附声 |
| 25–27 s | 导出点击、细小进度脉冲、完成和弦 |
| 29 s | 轻快上行完成铃；末尾淡出 |

重新生成音效：

```bash
python3 scripts/generate-audio.py
ffmpeg -y -i public/audio/editor-foley.wav -c:a aac -b:a 128k -ar 48000 -ac 2 public/audio/editor-foley.m4a
```

脚本默认输出 `public/audio/editor-foley.wav`，该 WAV 为本地中间文件，不提交仓库。转码后的 `public/audio/editor-foley.m4a` 包含在公开工程中，主动画实际引用该文件；正常运行 Remotion 无需 Python 或额外音频库。
